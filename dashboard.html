How to use

  1. Run python3 app.py in one terminal.
  2. Open dashboard.html in your browser or visit http://127.0.0.1:5000/.
  3. Enter login info and save clubs.
  4. Run python3 caddie_live_v5.py --dashboard in another terminal.
  5. Use arrow keys and n/p to move the simulator.
